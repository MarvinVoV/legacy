## 当前保留的代码

- 两轮 RPM 目标契约一致，去掉右轮隐藏 2.3% 目标偏置；启动、零曲率、STOP 等共用机械中位 1530µs。

- 固定航向直线 GOAL 保留 PI 与 GRV 测量微分阻尼，限制修正范围；不是世界坐标路径跟踪。
- 正常 GOAL 到达原容差后先禁止驱动、制动并继续计量；双轮新鲜反馈连续 50ms 满足既有 1RPM 停稳门槛后提交回中，等待 100ms，再按原 5mm/2° 容差确认结果。超时/故障不能报告成功，STOP 可立即打断。
- 路径外环默认关闭，电机细积分实验默认关闭，舵机方向 trim 为 0/0。失败的积分分离和方向曲率偏置实验已回退，不可按旧报告擅自恢复。

## 下一位 agent 的顺序

1. 先核对仓库、服务和设备实际状态；需要运动前可靠 STOP 并确认停车，再取得本轮空间/线缆就绪答复。不要重用旧授权中的物理就绪状态，也不要直接运行归档驱车脚本。
2. 新代码另建 `codex/` 开发分支。优先区分“单程直线精度”和“往返世界坐标回位”目标，拆分每段行驶与换向重锁参考的贡献；先离线读现有数据，不再根据单轮尺量盲调增益。
3. 保留当前功能性停车修复。若优化横偏，需要固定版本、固定参照的重复对照，不能拿同源积分当外部位置证据，不应要求用户无止境重复尺量。
4. 发布前补完整模式/速度、运行时长和通信异常实机验收；超声波实装后另验避障。完成测试再提交/合并；本次未获 push 授权。
