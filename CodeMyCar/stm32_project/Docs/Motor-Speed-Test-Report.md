## 2. 速度档位划分

轮半径 32.5mm，线速度换算：`cm/s = RPM × 0.3403`。

| 档位 | 电机 RPM | 线速度 | 典型用途 | 备注 |
|---|---|---|---|---|
| 精细低速 | 0–30 | 0–10 cm/s | 对位、微调、短距离 | 静摩擦占比大，起步差异最明显 |
| 常规低速 | 30–90 | 10–30 cm/s | Agent 常规移动 | 同步最好，推荐默认工作区 |
| 中速 | 90–180 | 30–61 cm/s | 快速转场 | Agent API 上限 60 cm/s ≈ 176 RPM |
| 高速/极限 | 180–300 | 61–102 cm/s | 仅调试/压力测试 | 300 RPM 时占空比 0.89，接近上限 |

> Agent API 的 `speed_cm_s` 范围是 1–60，因此**正常使用不会超过中速档**；180–300 RPM 属于电机能力验证。

## 6. 阶跃响应（30→60→120→30）

- 60 RPM：约 0.5s 到位，无超调；
- 120 RPM：约 0.7s 到位，无超调；
- 120→30 下降：119→45→33→31→30，平滑无下冲；
- 阶跃过程中左右差 ≤2 RPM；
- 30 RPM 低速上升比高增益版本慢（约 1–2s），是抑制振荡的代价。

## 7. Goal 距离测试（悬空，L1/STM32 goal 闭环）

## 8. 速度上限

- **300 RPM 可达**（L 297.0 / R 301.2），占空比 0.89，仍有约 11% 余量；
- 协议/Agent 层：Agent `speed_cm_s` 上限 60（约 176 RPM）；L1 `left/right_rpm` 上限 ±300。
- 结论：电机侧极限 ≈300 RPM（规格值），不需要继续加；实际可用工作区建议 ≤180 RPM。

## 9. 已知问题与后续

1. **反向低速 -30**：累计差 4.1%，右轮反向起步慢；如需对称，增加方向相关的低速前馈（需防超调），目前暂不做。
2. **航向漂移**：goal 直线每 10cm 约 0.9–1.0°（悬空里程计），落地后需实测；更长距离依靠收尾修正。
3. **转向机械不对称**：右极限约 65°，左约 90°；固件限幅 60°，最小转弯半径 83.1mm（pyserver 84mm）。
4. **位姿是航迹推算**：悬空测试累积的 pose 无物理意义；落地测试前建议复位。
5. **日志频率**：扫描时 10Hz（便于分析），最终固件 2Hz（不影响控制性能，仅日志量）。

## 10. 复现

```bash
# 1) 启动 broker + pyserver（pyserver 目录）
make dev

# 2) 速度扫描（轮子悬空！）
cd CodeMyCar/pyserver
.venv/bin/python scripts/motor_speed_test.py --hold 8 --targets=30,60,90,120,180,240,300
.venv/bin/python scripts/motor_speed_test.py --hold 8 --targets=-30,-60,-120,-300

# 3) goal 距离
curl -X POST http://127.0.0.1:8000/api/v1/agent/devices/DEV_1/move \
  -H 'Content-Type: application/json' -d '{"distance_cm":10,"turn_deg":0,"speed_cm_s":10}'
```
