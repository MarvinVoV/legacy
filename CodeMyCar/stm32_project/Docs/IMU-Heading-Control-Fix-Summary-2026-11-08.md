## 1. 背景

审查报告在 IMU 航向闭环、控制链路和硬件假设三个层面列出问题。本次按报告第 7 节
的优先级实施了两批修复，覆盖：

1. 安全提交与执行器（CTRL-03/05，CTRL-01 的限幅前提）；
2. 基本控制正确性（倒车符号、直行判定、最终限幅）；
3. IMU 生命周期（新鲜度、初始化恢复、制动冻结、积分管理）；
4. 几何与数据一致性（同比限速、读数失败、快照、归中出口）；
5. 安全链（超声波超时与近场快判）；
6. 功能（GOAL 接入航向闭环、遥测范围）。

## 2. 修复总览

### 2.1 IMU 数据层（`imu_service.c` / `imu_task.c`）

| 项 | 修改 | 对应编号 |
|---|---|---|
| 数据新鲜度 | `motion_service` 中若 `HAL_GetTick() - lastUpdateMs > 200 ms` 立即退出闭环 | IMU-P1-04 |
| 初始化恢复 | 失败后 2 s 退避重试；初始化后 1.5 s 无首帧则重开会话 | IMU-P1-05 |
| 零偏标定 | 只在 `gyroCount` 变化（新陀螺样本）时累计，运动中样本丢弃 | IMU-P2-02 |
| 数值健康 | 四元数必须有限且模长² ∈ [0.5, 1.5]，yaw 必须有限 | IMU-P2-03 |
| 一致读取 | 新增 `ImuService_GetSnapshot()`（seqlock），控制环只消费同一版本字段 | IMU-P2-05 |
| 遥测范围 | 航向回绕到 ±180° 后再量化，角速度限幅，非有限值丢弃 | IMU-P2-04 |

### 2.2 航向控制（`heading_control.c` / `motion_service.c`）

| 项 | 修改 | 对应编号 |
|---|---|---|
| 倒车符号 | 直行角度误差乘以速度符号 `sign(v)`，倒车不再正反馈 | IMU-P1-01 |
| 倒车角速度 | 门限改为 `fabsf(v) > 0.03`，`κ_meas = −ω/v` 保留带符号 v | IMU-P1-02 |
| 直行判定 | DIRECT 改为按曲率 `|κ| < 0.05`，同 RPM + 非零曲率不再误判 | IMU-P1-03 |
| 制动冻结 | `ctx->safetyBraked` 时退出闭环并 `Disable()` | IMU-P1-06 |
| 恢复重捕获 | `Disable()` 复位 `straightMode`/参考角/时间戳，恢复后重新捕获 | IMU-P2-01 |
| 积分生命周期 | 直行↔转弯切换清空对方积分；低速时角速度积分衰减 | CTRL-10 |
| 最终限幅 | 控制器输出（前馈+修正）统一限幅 ±3.770 1/m，LUT 不再越界失败 | CTRL-01 |
| 符号文档 | 头文件与代码注释统一：yaw 逆时针为正、κ 正=右转、ψ̇=−v·κ | IMU-P2-07 |

### 2.3 执行器（`servo_service.c` / `motor_service.c` / `motion_kinematics.c`）

| 项 | 修改 | 对应编号 |
|---|---|---|
| 立即命令 | `setAngleImmediate()` 先取消旧轨迹，死区只决定是否写 PWM | CTRL-05 |
| 动态目标 | 运动中同方向的目标刷新只更新目标、保留速度；仅反向重建轨迹 | CTRL-04 |
| 制动失败 | `MotorService_brakeAll()` 任一轮失败返回错误，安全路径记录 ERROR | CTRL-03 |
| 状态读取 | 新增 `MotorService_getStateEx()`；读取失败保留上次有效值，不当作停稳 | CTRL-11 |
| 同比限速 | 双轮任一超限时整体缩放，保持内外轮比例（曲率）不变 | CTRL-08 |
| 归中出口 | DIFFERENTIAL 与 GOAL 结束归中改用标定后的 `steer_straight_angle()` | CTRL-13 |

### 2.4 安全链（`safety_service.c` / `sonar_task.c` / `motion_service.c`）

| 项 | 修改 | 对应编号 |
|---|---|---|
| 通道时间戳 | `SafetyChannel.lastValidMs`，`safety_channel_update()` 增加 `nowMs` 参数 | CTRL-06 |
| 不可用判定 | `safety_channel_unusable()`：启用但 3 s 宽限后无数据、或 500 ms 未更新 | CTRL-06 |
| fail-safe | governor 对不可用通道按"被挡"处理并硬停（原为放行） | CTRL-06 |
| 近场快判 | 窗口内任一有效样本 ≤ stopCm 立即判挡，不等待中值窗口填满 | CTRL-07 |

### 2.5 功能

| 项 | 修改 | 对应编号 |
|---|---|---|
| GOAL 航向闭环 | 规划舵角→曲率→IMU 修正→同时更新舵机与双轮差速 | IMU-P2-06 |

## 3. 行为变化（使用注意事项）

1. **超声波启用但无数据时现在会硬停**（以前是放行）。上电后 3 s 内为宽限期；
   如果传感器未接好，车辆会在收到运动指令后立即短接刹车并打印
   `safety hard stop: sonar data missing/stale`。
2. **倒车直行现在由 IMU 修正**，方向与前进相反，属有意设计。
3. **GOAL 受 IMU 影响**：规划曲率会被航向环修正，双轮差速随之调整。
4. **舵机动态目标不再反复从零速起步**，闭环刷新时保持速度；只有反向时重建轨迹。
5. **制动失败会被记录**：`SAFETY brake failed (wheel not braked)` 表示至少一轮
   未成功加锁制动，此时不应认为车辆已安全停住。

## 5. 仍未修复的部分与原因

| 编号 | 问题 | 未修原因 | 建议 |
|---|---|---|---|
| **CTRL-02** | STOP/故障停车可能被旧运动快照覆盖 | 需要"命令代次 + 单一执行器写入者"的架构改造：所有命令通过消息/邮箱提交给 MotionTask，STOP/故障用不可覆盖的锁存；局部补丁无法消除检查与写入之间的竞争 | 单独排期，作为控制架构重构的第一项；在此之前避免在运动中依赖软件 STOP 的唯一性 |
| **CTRL-12** | 共享运动/GOAL 状态锁保护不完整 | 与 CTRL-02 同源：命令任务在锁内写目标，运动任务大部分 GOAL 步进/状态写入未持同一把锁 | 与 CTRL-02 一起改为单写者 + 状态快照 |
| **CTRL-09** | DIFFERENTIAL 模式与阿克曼机械约束不符 | 该模式目前兼作台架诊断（原地差速旋转），是否保留为正式移动模式需产品决策 | 若保留诊断：明确门控（如仅在无租约的台架模式可用）；若作为正式模式：改为 v/ω→可行曲率并拒绝 pivot |
| **HW-02** | 倾斜安装时 `gyro.z` 不等于世界竖直轴偏航角速度 | 需要传感器到车体的安装矩阵，当前为水平安装（Z 轴垂直）时可忽略 | 若改为立式安装，先测量安装矩阵并对三轴陀螺做变换 |
| **HW-03** | 零偏慢跟踪可能吸收真实慢转 | 已加"仅新样本 + 静止判定"约束，但静止判定仍只依赖角速度阈值 | 结合加速度稳定度/轮速确认静止；长期方案是信任 SH-2 校准输出 |
| **HW-04** | 舵机平滑到达与轮速差立即生效不同步 | 需要实测舵机响应延迟后再设计可执行曲率轨迹 | 落地测量舵机阶跃响应，再决定是否引入曲率轨迹同步 |
| **HW-05** | 轮速同步环、IMU、trim 与前馈缺少统一分工 | 属调参/架构优化，需实车数据支撑 | 落地整定时统一：外环定曲率、内环跟转速、同步环仅在直行小幅工作 |

## 6. 待完成的验证（硬件）

1. 悬空：前进/倒车各给一次航向扰动，确认舵机修正方向相反；
2. 拔掉 IMU：确认 200 ms 内退出闭环、恢复后重新捕获参考航向且无舵机跳变；
3. 拔掉超声波（启用配置下）：确认 3 s 宽限后或 500 ms 超时后硬停；
4. 低速落地直行（2 m）、倒车（1 m）、固定曲率绕圆；
5. 以上稳定后再提高速度并整定 PI 参数。

> 完成第 4 项前不建议高速落地调参；CTRL-02 未修复意味着"软件 STOP 的绝对优先"
> 仍依赖当前调度时序。
