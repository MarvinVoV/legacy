# STM32 / ESP32 独立供电验收

日期：2026-11-14。当前开发分支：`codex/motor-low-speed-progress-guard`。

## 最新状态：A组未完整通过，暂停动作

A组联网/90秒待机、IMU以及双轮正反转实物通过，但舵机延长复测发生剧烈抖动，用户要求停止。已可靠STOP两次（seq73/74），用户确认TB6612关闭、舵机已停止。B/C组均未执行。先断电核对TB6612信号GND到STM32 GND的实际直连接触；没有确认前不得恢复动作。

## 目标与起点

目标是同一路外部稳压5V给两块主板供电，TB6612/舵机继续使用原电池与驱动板供电。已验收的双USB起点、信号表、固件身份和低速保护修复见 [Motor-Servo-Dual-USB-Verified-Baseline-2026-11-14.md](../../../stm32_project/Docs/Motor-Servo-Dual-USB-Verified-Baseline-2026-11-14.md)。

不在供电实验中改固件、PID、中位、UART、编码器/方向/PWM线。两板GND保持直接相连，TB6612信号GND保持直接接STM32；IMU取STM32 3V3/GND，不接外部电源板3V3，不接RST。改变一块主板的电源时，不同时把板间共地改到供电板中转。

## 实验矩阵

| 组别 | ESP32供电 | STM32供电 | 本轮状态 |
| --- | --- | --- | --- |
| 已验收起点 | 电脑UART USB | 电脑USB/ST-LINK | 双轮正反转、停车、舵机通过 |
| A | 外部模块5V/GND，无USB | USB | 待机/电机通过；舵机剧烈抖动，A组未完整通过，已断驱动电源暂停 |
| B | USB | 外部模块5V/GND，无USB | 未执行 |
| C | 同一外部模块5V/GND | 同一外部模块5V/GND | 未执行 |

每次换线先关闭驱动与独立电源并断开主板USB；完成后恢复该组所需电源。一块主板不同时连接USB和外部5V。本轮A：模块5V→ESP32 5V、模块GND→ESP32 GND；STM32恢复USB，UART/板间直接共地/IMU/TB地线不改。

## 每组证据与放行条件

1. TB6612关闭，先采90秒被动数据：ESP心跳及uptime、会话ID、STM32连接与运动状态新鲜度、IMU计数/年龄、任务健康与故障日志。初次上电前缓存不算新数据；采集期间重启/断连必须记录。
2. 仅读通过后，现场确认驱动上电稳定、车轮悬空，再单独验收后轮正反转/停车及舵机。运动命令持续刷新租约，监测ACK、实测速度/fault；任何异常finally可靠STOP。
3. 正常工作必须有实物反馈；ACK/state=running不能代替轮子转动。若新保护报error8，表示有命令/足够输出而无编码器进展，不得反复清故障重试或取消保护。
4. 一次通过只代表对应配置和时间窗口。最终C组仍需重复冷启动、带载与较长运行验证；A或B通过不能替C验收。

若A失败，优先隔离ESP供电支路/冷启动；若B失败，优先隔离STM32供电支路；若A、B分别通过而C失败，优先检查共用电源的负载能力、接线压降及共用回路。以上是后续排查顺序，不是无需实测即可认定的故障原因。

## 解释边界

当前没有供电电压/纹波/瞬态波形的独立测量，也没有确认新供电模块准确型号和额定能力；不能仅凭心跳通过宣称电源电气质量合格。INA219逻辑端未取得有效测量，available=false不能拿来证明主电源电压正常。电机主电源与主板5V是两路不同供电，测试中分别记录其开关状态。

本轮不重新讨论/改动旧供电板，也不把历史间歇不转预先归为某个硬件损坏。证据优先保存到独立的 `Docs/validation/independent-power-2026-11-14/`，避免混淆双USB已验收起点。

## 接线澄清与改用充电宝USB直供对照

用户确认恢复双USB时，ESP32接独立电源板的5V和GND两根均已拔掉；不是USB与外部5V并联。用户同时澄清，TB6612信号GND直连STM32，舵机VCC/GND接TB6612的5V/GND输出。若板内两个GND相通，这种接法已经共地，不能因没有额外舵机GND→STM线就指认漏接地；板内连续性没有实测，不能断言有/无。

为收敛“独立供电支路”与“USB额外接地路径”两类因素，B/C暂缓，下一步先用同一根USB线把ESP的电脑端换插充电宝5V USB，STM电脑USB及全部UART/GND保持不动、独立电源板5V/GND继续断开。已请求用户TB6612保持关闭、接好后先查连接，再单独验收舵机。此对照绕过供电模块和外接5V/GND线，但保留ESP的USB供电入口与线缆。

若该配置稳定，优先定位独立电源板及到ESP的供电支路；若也抖动，优先检查失去电脑USB附加地通路后的参考地/回流接触。两者都是进一步缩小范围，不能仅凭一次通过唯一认定器件损坏。没有收到就绪前不发动作指令。
