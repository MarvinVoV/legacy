# Phase 13：转向百分比映射实施与验证

日期：2026-11-01
分支：`codex/calibrate-left-steering-range`

## 目标

上层不再尝试表达难以精确测量的“真实前轮角度”，而是使用归一化转向百分比。STM32 根据左右连杆的实测差异，把百分比映射为舵机原始偏移角。线协议仍为固定 9 字节，不增加带宽。

接口约定：

- `steer_percent`：整数，范围 `-100..100`
- `0` 为居中，负值左转，正值右转
- 推荐控制档位：`-100/-75/-50/-25/0/25/50/75/100`
- 档位之间允许输入任意整数，由 STM32 线性插值
- 旧 `steer_angle` 暂时兼容；其 `-600..600` 按 `-100%..100%` 缩放

## 标定表

| 上层百分比 | 左转舵机原始偏移 | 右转舵机原始偏移 |
|---:|---:|---:|
| 0% | 0° | 0° |
| 25% | 15° | 10° |
| 50% | 30° | 15° |
| 75% | 45° | 24° |
| 100% | 60° | 32° |

这里的“原始偏移”是相对舵机中位的命令量，不等于单个前轮的真实转角。左右表不同是有意的软件补偿。

## 各控制模式

- `DIRECT`：百分比经标定表直接变为舵机偏移。
- `DRIVE`：百分比同时转换为标称等效转角（`100% = 25°`）用于差速计算，并经标定表驱动舵机。
- `GOAL`：规划器产生的标称等效转角反算为百分比，再经相同标定表驱动舵机。

当前标称最小转弯半径按轴距 144 mm 和等效转角 25° 设置为 308.8 mm。这是运动学近似值，不应解读为任一前轮的实测角度。

## 自动验证

- STM32 host tests：通过，包括全部标定锚点、插值、越界和非数输入。
- STM32 Debug firmware：完整构建通过。
- ESP32 firmware（ESP-IDF 6.1）：完整构建通过；8 MB Flash，应用分区余量约 33%。
- pyserver tests：80 passed，包括服务端最小转弯半径与 STM32 标称模型一致性检查。
- serial packet protocol tests：5/5 passed，覆盖新字段编码、旧字段兼容和越界拒绝。

## 悬空硬件验证

两块板刷入同一开发分支的已提交固件，DIRECT 模式保持左右电机 0 RPM。为避免安全租约在舵机平滑运动完成前归中，测试期间用不同序号短时续租，读出 PWM 后立即下发 STOP。

| 命令 | 标定目标 | TIM2 CCR1 实测 | 结果 |
|---|---:|---:|---|
| 左 75% | 舵机 135°（左偏移 45°） | 2000 μs (`0x7D0`) | 通过 |
| 右 75% | 舵机 66°（右偏移 24°） | 1233 μs (`0x4D1`) | 通过 |
| STOP | 舵机 90° 中位 | 1500 μs (`0x5DC`) | 通过 |

STOP 后 pyserver 状态为 `idle`、左右轮速均为 0、设备在线、STM32 链路正常、无故障。以上验证确认“上层百分比 → ESP32 编码 → STM32 解码 → 左右标定表 → PWM”的完整链路正确；机械真实轮角仍以人工观测的标定数据为依据。

## 实车验收要求

车辆悬空、驱动轮速度为 0，依次下发左右 25%、50%、75%、100%，确认：

1. 方向正确且每档随百分比单调增大；
2. 100% 时连杆、轮胎不碰车架；
3. 左右相同百分比的视觉转向幅度大致接近；
4. 最后下发 STOP 并确认舵机归中、系统无故障。

肉眼/相机测量存在误差，因此本表是当前机械装配下的工程标定，不声称实现严格的“真实角度闭环”。若机械结构、舵机臂安装齿位或中位发生变化，必须重新标定。
