# Phase 8：MOTOR-01 低速方向差异修复验证

日期：2026-11-01  
分支：`codex/fix-remaining-runtime-safety`

## 1. 根因与修复

悬空实测表明，两轮彼此的稳态差异不大，主要缺陷是同一电机正转所需占空比较反转高约 12%～18%。原配置只有随低速衰减的统一前馈系数，无法表达方向相关的机械摩擦。

修复内容：

- `MotorSpec` 增加正转方向标定系数，非法或未配置值回退为 1.0；
- 当前两轮正转标定为 1.15，反转路径保持不变；
- 修正速度扫描脚本，使其以 5Hz 刷新连续命令租约并检查 HTTP 错误。旧脚本只发一次命令，500ms 后车辆已因租约停车，后续所谓稳态样本无效。

没有修改 PID 参数，也没有用悬空数据推断落地负载参数。

## 2. 相同工况前后对照

条件：轮子悬空；每个目标保持 5 秒；统计最后约 4 秒；单位均为 RPM。

| 目标 | 修复前左/右 | 修复后左/右 | 修复前最大误差 | 修复后最大误差 |
|---:|---:|---:|---:|---:|
| +20 | 17.1 / 15.2 | 19.6 / 21.2 | 4.8 | 1.2 |
| +30 | 26.6 / 25.0 | 32.2 / 30.0 | 5.0 | 2.2 |
| +40 | 35.1 / 33.2 | 42.5 / 39.9 | 6.8 | 2.5 |
| +60 | 50.2 / 48.1 | 61.4 / 60.1 | 11.9 | 1.4 |

反转回归在 -20、-30、-40、-60 RPM 下最大稳态误差分别为 0.8、3.3、1.5、2.6 RPM，没有出现方向补偿串入反转路径的问题。

## 3. 自动化、构建与刷写

- STM32 host suite 全部通过；
- Debug 固件构建通过，FLASH `86428 B / 1 MiB`；
- STM32CubeProgrammer download、verify、reset 成功；
- 扫描脚本 `finally` 路径下发零速，测试结束车辆为停止状态。

## 4. 结论与边界

`MOTOR-01` 的悬空低速启动和方向性稳态差异已显著收敛。+30/+40 RPM 左轮存在约 2.2/2.5 RPM 的轻微超调，低于原先 5～7 RPM 的欠速，当前不继续提高控制增益。

落地后负载、轮胎和电池电压会改变摩擦模型，因此仍需用同一脚本做落地低速直线校准；未经落地数据，不把悬空系数继续细调到单点零误差。
